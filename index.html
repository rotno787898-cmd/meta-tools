১. API Key সেটআপ (একবারই)
Key শুধু আপনার ব্রাউজারেই সেভ থাকে। ক্রম: Gemini → Claude → ChatGPT। একটির লিমিট শেষ হলে স্বয়ংক্রিয়ভাবে পরেরটিতে যায়। যেগুলো নেই ফাঁকা রাখুন।
মডেলের নাম (দরকার হলে বদলান)

২. প্ল্যাটফর্ম ও সেটিংস

টিক না দিলে ডিফল্ট স্মার্ট প্রম্পট চলবে, যা প্রতিটি ছবি দেখে নিজেই ধরন বুঝে লেখে। টিক দিলে আপনার প্রম্পট ব্যবহার হবে। অক্ষর/কিওয়ার্ডের সীমা ও JSON ফরম্যাট টুল নিজেই জুড়ে দেয়।
নিয়ম বদলাতে পারে, তাই সংখ্যাগুলো প্ল্যাটফর্মের বর্তমান গাইডলাইনের সঙ্গে মিলিয়ে নিন।

৩. ছবি দিন

📁 এখানে ট্যাপ করে ছবি বেছে নিন
অথবা ছবি/ভিডিও ড্রপ করুন (JPG, PNG, SVG, WebP, MP4, MOV, EPS, AI)
EPS/AI-এর জন্য: ব্রাউজার EPS দেখতে পারে না, তাই একই নামের JPG/PNG প্রিভিউ-ও একসঙ্গে দিন (যেমন logo.eps + logo.jpg)। AI প্রিভিউ দেখে মেটাডাটা লিখবে, আর CSV-তে নাম আসবে logo.eps

📖 কীভাবে ব্যবহার করবেন

টুলটি ১০০% ফ্রি। আপনি নিজের AI Key বসাবেন, ছবি সরাসরি আপনার ব্রাউজার থেকে AI-তে যায়। আমাদের কোনো সার্ভারে কিছু জমা হয় না।

ধাপ ১: ফ্রি Gemini Key নিন (২ মিনিট)

  1. aistudio.google.com-এ Google অ্যাকাউন্টে লগইন করুন।
  2. Get API key → Create API key চাপুন।
  3. Key কপি করে টুলের "Gemini API Key" ঘরে বসান, তারপর সেভ করুন।

ধাপ ২ (ঐচ্ছিক): ব্যাকআপ Key

Gemini-র ফ্রি লিমিট শেষ হলে টুল নিজে থেকে Claude, তারপর ChatGPT-তে চলে যায়। এগুলোর Key নিতে পারেন console.anthropic.com ও platform.openai.com থেকে। এগুলো পেইড, চ্যাট সাবস্ক্রিপশন থেকে আলাদা, তাই ক্রেডিট কিনতে হয়। না চাইলে ফাঁকা রাখুন।

ধাপ ৩: প্ল্যাটফর্ম ও সেটিংস

  • Adobe Stock / Shutterstock / Vecteezy বেছে নিন।
  • অক্ষর ও কিওয়ার্ড সংখ্যা প্ল্যাটফর্মের বর্তমান নিয়মের সঙ্গে মিলিয়ে নিন (নিয়ম বদলাতে পারে)।
  • ছবির ধরন "অটো" রাখলেই হবে, AI ছবি দেখে নিজেই বুঝে নেয়।

ধাপ ৪: ছবি দিন

  • একসঙ্গে অনেক JPG/PNG/SVG/WebP দিতে পারবেন।
  • ভিডিও (৮-১০ সেকেন্ডের ক্লিপ): MP4/MOV দিন। টুল ভিডিওর ভেতর থেকে ৪টি ফ্রেম নিজে বের করে AI-কে দেখায় (ভিডিও কোথাও আপলোড হয় না)।
    EPS/AI: ব্রাউজার EPS দেখতে পারে না। তাই একই নামের JPG/PNG প্রিভিউ-ও দিন (যেমন logo.eps + logo.jpg)। দুটি একসঙ্গে সিলেক্ট করুন। AI প্রিভিউ দেখে লিখবে, আর CSV-তে নাম আসবে logo.eps।

ধাপ ৫: তৈরি করুন

মেটাডাটা তৈরি করুন চাপুন। প্রতিটি ছবির নিচে ফলাফল আসবে। ঘরে ক্লিক করে নিজে এডিট করতে পারবেন, সব কপি দিয়ে সাইটে পেস্ট করতে পারবেন, অথবা CSV ডাউনলোড করে সাইটে ইমপোর্ট করতে পারবেন (প্রতিটি সাইটের CSV অপশন আলাদা, সাইটের বর্তমান নিয়ম দেখে নিন)।

নিজের প্রম্পট

সেটিংসে "কাস্টম প্রম্পট" টিক দিয়ে নিজের নির্দেশ লিখুন। "ডিফল্ট প্রম্পট লোড করুন" চেপে আমাদেরটা এডিট করেও নিতে পারেন। সীমা ও JSON ফরম্যাট টুল নিজেই জুড়ে দেয়।

সমস্যা হলে

  • "লিমিট/কী সমস্যা": Key ভুল বা ফ্রি লিমিট শেষ। টুল পরের AI-তে যায়, আর "লিমিট রিসেট" বাটনে আবার চেষ্টা করা যায়।
  • সব ব্যর্থ: ইন্টারনেট ও Key ঠিক আছে কিনা দেখুন, অথবা মডেলের নাম বদলে নিন।
  • EPS লাল চিহ্ন: একই নামের JPG/PNG প্রিভিউ যোগ করুন।
গোপনীয়তা: ছবি আপনার বেছে নেওয়া AI প্রোভাইডারের কাছে যায়। Gemini-র ফ্রি টিয়ারে গুগল ইনপুট নিজেদের সার্ভিস উন্নতিতে ব্যবহার করতে পারে, তাই গোপন বা ক্লায়েন্টের ছবি ফ্রি Key-তে দেবেন না। AI-র লেখা সবসময় একবার দেখে তবে সাবমিট করুন।
